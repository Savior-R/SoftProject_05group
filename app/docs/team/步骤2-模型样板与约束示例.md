## 四种生成列唯一约束

MySQL没有本项目可用的WHERE过滤唯一索引；统一将不参与约束的行映射为NULL，再建唯一键。示例都使用`Computed(expression, persisted=True)`及`UUIDText()`，生成列可空，插入/更新DTO中不能包含它。不要给它设Python default或server_default。唯一键允许多条NULL，不要把辅助列设为NOT NULL。

| 主责/目标 | 生成表达式 | 唯一范围与必验负例 |
|---|---|---|
| F：`teacher_review.active_primary_report_id` | `CASE WHEN is_primary=1 AND status='reviewed' THEN report_id END` | pending/returned及非主批均不占位；第二条有效主批必须失败；保留`unique(report_id,teacher_id)`和reviewed分数/时间CHECK |
| D：`trial_session.active_user_id` | `CASE WHEN status IN ('running','paused') THEN user_id END` | not_started可有多个；running与paused共同占位；终态释放；第二个活动场次失败 |
| D：`session_time_span`的open辅助列 | `CASE WHEN end_at IS NULL THEN session_id END` | 同场多条已关闭span合法；第二条open失败；保留`unique(session_id,span_no)`；字段名仍为`start_at/end_at` |
| F：`evaluation_attempt`的活动report辅助列 | `CASE WHEN status IN ('queued','running') THEN report_id END` | 同report最多一个queued/running；终态释放；保留`unique(report_id,attempt_no)` |

05对后两种辅助列给了语义但没有冻结名称，示例的`open_session_id`/`active_report_id`只是样板名称，正式名称由域负责人提交A审查并进入最终manifest。除了上述四种，05要求的软删唯一语义仍须逐表核对，不能从“两个示例”推断全项目只有两处生成列。

有效主批和活动场次唯一键只是数据库兜底。业务步骤6/8/9仍须按04锁user/report、使用同一连接事务、维护outbox和版本、将冲突映射为契约错误；步骤2最小样板不证明这些服务流程已经实现。`check_expression.py`只能规范化比较CHECK表达式，不能独自证明唯一键或生成列的实际行为，必须看真实MySQL正负例。

## 循环外键

样板使用`Report.published_attempt_id → Attempt.attempt_id`和`Attempt.report_id → Report.report_id`，全部FK保留。`compile_metadata()`先创建环中所有表，再通过`ALTER TABLE ADD CONSTRAINT`加循环FK；实库测试验证非法指针和孤儿attempt被拒绝，不关闭FK检查规避建表。

业务创建顺序：先创建report且指针为NULL → 创建引用该report的attempt → 结果有效后在受控事务回填published指针。不能把“循环DDL可创建”理解为“可以插入缺失的父记录”；不能写一个只补字符串、从不解析目标模型的FK。实际业务发布与旧结果保留规则按04/05实现。

## 如何复跑

从`app/backend`运行（Python3.12、依赖已按lock安装）：

```powershell
# 配置文件需由A在本机提供，仅含DB_ROOT_PASSWORD/DB_DEV_HOST/DB_DEV_PORT；不可入库或发群。
$env:STEP2_BOOTSTRAP_ENV = '你的私有配置文件绝对路径'
.\.venv\Scripts\python.exe -m pytest tests/integration/test_model_examples.py -q
```

测试仅在新的随机`test_a..._`七库和临时账号执行DDL，退出时只清理自身记录的对象；不使用预建的`test_g1_`库，不修改现有共享库。需要管理员建库/账号权限，仅限A确认的本地隔离实例；普通成员可先读样板，域约束集成测试由A安排受控环境。运行后生产manifest仍应为61 expected/4 registered/57 missing，不能生成4表生产快照。
