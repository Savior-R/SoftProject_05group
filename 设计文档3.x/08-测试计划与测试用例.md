## 1 测试状态与策略

本文件为待实施测试。文档结构和04/11纯函数参考检查可独立执行，结果见文档校验结果.json；不能据此把应用、数据库、浏览器、模型、性能标通过。旧TC归档于原目录，新版采用TC3避免误继承结果。

分层：纯函数/DTO→两方言repository→HTTP/WS/媒体端到端→真实AI效果→故障/负载→角色UAT。身份、主批、上传、次数以真实SQL/对象字节验证，mock不代替约束。固定版本、配置、迁移ID、seed manifest、浏览器、硬件及provider能力清单；每例记录请求、SQL断言、hash、attempt/event/score_version与日志。

进入：01/05/06/11冻结、G1完成、应用可启动、四角色/两院系/三班测试数据与授权素材就绪。退出：当前阶段必需FR通过、阻断/高优先缺陷清零，适用G1–G6都有证据。阻断=建库/启动/闭环失败，高=越权/丢媒体/错最终分/假证书，中=可绕行功能错，低=视觉瑕疵；不能人工改库代替修复。

## 4 AI效果专项（G3/G5）

| 指标 | 固定样本/方法 | 目标 |
|---|---|---|
| AI对教师分 | ≥50份跨学段/学科真实试讲，双教师盲评、分歧仲裁；无分样本另报覆盖率 | 各维及总分MAE≤8；缺维率/误差分布不可隐去 |
| 知识错误 | 教研标注正负片段 | precision≥85%、recall≥75%，混淆矩阵 |
| ASR | 清晰普通话人工稿，噪声/专名挑战集分列 | 主集CER≤8%，挑战集不混算 |
| 口头禅 | 20段人工标注 | 差≤±1次/分钟，歧义词单列 |
| 环节 | 人工边界及缺失标注 | 边界误差≤±10秒，缺失另报precision/recall |
| 建议 | 双教师5分评价，≥4为可用 | 可用≥80% |
| 证据定位 | verified问题点对真实帧/句，approximate单列 | 误差≤0.5秒，不能把粗定位计入精确通过数 |
| 长样本 | 真实10/45分钟，跨片重复、静音、暂停 | offset单调不越界、缺片可恢复，耗时/费用可追溯 |

模型/提示词/抽帧/对齐/规则任何变更回归固定集，新增样本不能替掉失败样本。正式考核/证书需要verified，不满足则门禁不放行。

## 5 性能与容量（G6）

| 场景 | 负载 | 目标/口径 |
|---|---|---|
| REST | 200VU混合读取 | P95≤500ms，错误<0.1%，不含媒体传输 |
| 控制WS | 200场×(1学生+4教师)=最多1000业务连接 | P95≤300ms，指导≤1s；60虚拟学生不独立建连接 |
| WebRTC | 每场4观摩，直连/TURN分别测 | 媒体P95≤2s，记录上行/中继/丢包/恢复 |
| 评测 | 真实10分钟样本，pipeline并发与50路ASR分别限流 | submit接受至发布≤5分钟比例≥95%，含排队；300s告警/600s失败 |
| 上传 | 100路真实part含45分钟录像 | hash零损坏，续签/恢复正确，记录内存/吞吐 |
| 报告热点 | 500QPS，保留在线权限检查 | P95≤200ms，缓存命中目标≥90% |
| WS阶梯 | 从小规模递增、独立压测机 | 记录延迟/掉线/CPU/内存拐点，安全上限×0.7 |
| 成绩传播 | 高频改分、乱序重复事件 | 60秒更新目标，与全量重建一致 |

实例数=ceil(目标连接/(单实例实测上限×0.7))。媒体带宽/模型配额单独测，不用本机小规模线性外推200场；5k/10k可作独立控制面极限试验，旧13000连接不再作为业务模型。模拟provider只能验证内部调度，不作为真实AI SLA证据。

报告含脚本版本、硬件、账号配额、流量、P50/P95/P99、错误分类与费用。尚无实测前所有并发/时效都是设计目标。

## 6 安全、恢复和UAT

越权覆盖HTTP/WS/RTC/短链/导出/证书；验证注入、XSS、伪类型上传、超大文件、短链过期、提示词注入、日志泄密。SQL不可用fail closed，测试refresh并发轮换、已用token重放、退出和收权。恢复覆盖DB、Redis清空、worker终止、租约失效、API重启、S3中断、ASR429/超时、outbox崩溃；恢复后重建投影对账，RPO/RTO按09演练。

四角色各完成真实流程；键盘/读屏/codec/布局与对比度人工验收随G6提交。只通过文档检查不能关闭这些用例。
