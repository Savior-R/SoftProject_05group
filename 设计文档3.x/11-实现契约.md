## 0 使用方式与类型语法

06逐端点引用本文件DTO，05按同名数据结构持久化；本版不保留旧U-01/U-26“已修但仍待加列”的矛盾说明。API附件与本表同源。以下字段`?`可省略，`|null`允许显式空，其他均必填；extends展开父DTO。`Partial<T>`只把可写字段变可选，空对象拒绝；`Page<T>`固定items:array<T>,total:int,page:int,page_size:int。路径uuid/serial/part_no见06。所有DTO默认禁止未知字段。

number序列化JSON数值，后端解析为Decimal并拒绝NaN/Infinity。uuid为小写带连字符，时间datetime为UTC ISO8601带Z，date为YYYY-MM-DD。输入时区偏移可解析成UTC；输出固定Z。string长度按Unicode字符，密码另校验UTF8字节≤72且8–32字符含字母数字。

## 1 认证、权限与安全会话

access JWT: iss=ai-teach,aud=web,sub=user_id,sid=security_session.sid,jti=uuid,role,profile_id,auth_version,perm,iat,exp,token_type=access；2小时有效。refresh为随机256bit不透明token，仅存SHA256至security_session，绝对到期7天；每次refresh原子旋转并更新hash，前端单飞去重，旧refresh再次使用撤销该family。只在本端点接收refresh，不能当Bearer访问业务。

每个受保护请求读取SQL user.status/auth_version与security_session.revoked_at/expiry；token中的role/perm必须与当前版本相符。scope从当前组织关系解析；权限变更/班级范围变更后递增受影响user.auth_version并撤销会话，在变更事务提交后下一请求拒绝旧token。SQL不可用返回503，不跳过鉴权。WS握手及每次客户端业务命令同检查；服务器主动推送前亦检查接收会话撤销标记，最长1秒轮询关闭。

登出撤销当前sid；改密/找回/停用/权限变更撤销所有受影响sid。must_change_password=true时只允许GET me、change-password、logout、refresh；refresh仍保持该标记。改密成功后清标记、增加auth_version、返回reauth_required=true，旧token均失效。重置接口只向管理员返回一次随机密码，不写日志。

登录失败计数在user.login_fail_count/window_at事务更新；15分钟窗口5次失败锁15分钟；成功清失败计数，不提前清must_change_password。account-locked返回剩余秒数。SMS验证码仅哈希存运行态TTL300秒、一次性消耗，生产短信必须真发；本地mock只允许ENV=demo，UI标模拟短信并禁公网开放注册。

### 跨字段校验与字段披露

- ClassIn的major.department必须等于department_id；新增用户院系来自班级/管理员范围，不允许学生自报另院。组织迁移必须由系统管理员受控执行，不放进普通UserPatch。
- TaskIn的scenario_id/structured_q_ids存trial_task.config_json，响应展开同名字段：scenario模式要求scenario_id；structured要求非空structured_q_ids且topic_ids空；free要求topic_ids非空或允许同学科题库选择。rubric必须published且subject/stage兼容。deadline>now。task.publisher_id为teacher_profile.teacher_id（管理员创建可NULL），鉴权创建人统一trial_task.created_by；rubric.publisher_id为user_id，不混用。
- SessionIn有task_id时mode/planned_duration_s/rubric_id由task派生，传入不一致422；topic在指定集内或同学科可用题库。自由练习必须mode/rubric_id/planned_duration_s，free/scenario要求topic_id，scenario还需scenario_id；structured要求q_id且topic_id空。
- RegisterIn不接受teacher/admin，不预建consent。公开资源和学生场次快照不返回answer_outline；教师凭scope读取参考答案。structured评分输入q_text+rubric，内部参考答案可供教师，不与学生响应混用。
- RubricIn.grade_bands默认在服务端补60/80/90后落快照；items必须六维各至少一项、每维权重和1、max_score>0、主体与ai_enabled一致。PATCH published创建新draft且重建item_id，不能让历史人工item_id引用新版本。
- Resource类input中的*_upload_id只能引用本人完成且用途正确的upload，输出*_url由签名播放/下载路由生成，不允许提交任意外部file_url。owner_id和department_id由服务端填；学生只读本院或系统共享的enabled/published资源，教师可额外看本人未发布内容。试讲source=teacher_created；结构化source=mock；十类QuestionCategory、模板teaching_plan、建议example_clip/drill沿用原模型，不能随意换拼写。
- API Group.member_ids/leader_id均为user_id，持久化关联表使用student_profile.profile_id，服务端查询映射且校验同班。UserRow.profile_id在teacher为teacher_id、student为profile_id，管理员为user_id，不能用于推导教师资格。
- 候选池写trial_session.runtime_json，创建时session_snapshot只保存配置，运行状态不能回写冻结配置。process_restart属于runtime device flag和span关闭原因，最终场次状态为aborted，不新增未定义的session枚举。
- Voice点评只允许completed、owner本人、purpose=review_voice、target=session_id，≤300秒/10MiB；客户端录WebM/Opus或其他探测支持格式，服务端转m4a供播放。输入voice_upload_id，DB保存服务端派生voice_comment_url对象key。
- SessionSubmitIn.manifest_hash按recording_id/track_type/checksum/duration_ms及no_input_tracks排序后规范化SHA256，服务端重算，不能信客户端hash。required_tracks来自session_snapshot。require_video=true必须portrait+audio；screen/board仅声明使用时必需，未使用明确no_input；不伪造空文件。
- Report在未发布初次状态dimensions仍按六维返回unavailable和缺失原因，latest_attempt可queued；DTO中的latest_attempt允许null仅限report刚创建同事务尚未返回，API返回前必须补齐。原始provider响应和敏感rubric参考答案仅教师/管理员可按权限查询，不进公开Snapshot。
- RubricMutationOut固定200，以created_new_version标识新版本；所有领域创建默认201；异步提交202；删除204必须无body。客户端不提交可信total_score/score/recommendation。

## 3 状态机与时间轴

| 对象 | 合法迁移 | 条件/副作用 |
|---|---|---|
| session | not_started→running(start)；running→paused(pause)；paused→running(resume)；running/paused→finished(finish)；未终态→aborted(abort) | start原子分次数和span；finish停止采集但不触发评测；结束不可再次start |
| task | draft→published(publish)→ongoing(first_start)→closed(close/deadline)→reviewed(all_reviewed) | published也可直接closed；每分钟扫描截止；无人提交不自动reviewed；同版本不可回退 |
| rubric | draft→published→disabled | draft PATCH原地；published PATCH新建下一draft；版本号事务分配唯一 |
| review | create→pending→reviewed(submit)；pending/reviewed→returned(return)；returned→pending(reopen)；reviewed→reviewed(submit修改) | reviewed全细则必填；pending不占有效主批；returned禁止直接submit |
| report首次 | calculating→finished/partial/failed；finished→teacher_reviewed；teacher_reviewed→finished/partial(撤销有效主批) | 发布状态由当前快照与主批决定；新attempt另显示，不抹旧成功 |
| attempt | queued→running→succeeded/partial/failed | 终态不可改；重算新增attempt，generation防旧worker覆盖 |
| upload | uploading→completed/failed/aborted | failed可重新init建立新upload_id；completed不可重写分片；同complete幂等 |
| training | running→submitted→evaluating→finished/failed；非终态→aborted | complete不收score，实际评分成功才completed_at非空 |
| exam | preparation→trial→defense→submitted→finished；非终态→aborted | 提前advance显式确认，晚于deadline自动推进；无录像/成绩则不finished |
| certificate | 签发→valid→expired；valid/expired→pending_review(依据变更)；pending_review→valid/expired或revoked；valid/expired→revoked | 撤销不可逆；retain时仍按expiry决定valid/expired；公开验真pending_review=false |
| export | queued→running→success/failed；success→expired | 7天到期；expired不伪装任务失败 |

没有列出的迁移返回state-conflict或领域错误。first_start、all_reviewed和派生事件幂等；closed任务有新退回批阅时状态无需回退，页面显示“需复核”，记录派生刷新，不改已截止事实。

### 3.1 活动时钟与录像

offset_ms相对有效教学开始，排除全部pause；span使用绝对UTC记边界。行为事件/字幕/问题点/录制/计时共享活动轴。heartbeat_at每2秒落SQL，展示插值不增加业务权威时间。scene脚本at_ms按活动轴调度，独立100ms或更细轮询，目标±200ms；引擎tick仍每秒。

用户暂停所有轨道recorder.pause，WebRTC停止发送；恢复继续同容器流，FFprobe校验。屏幕分享被系统中断标录制缺口，若必需轨道则阻止submit并提供重做，不把中断段补黑后声称完整。process_restart保守关闭到heartbeat并abort需重新采集；缓存命中也不能把不同媒体的结果套进新场次。

### 3.2 正式次数与冻结配置

allow_retry为额外重做数，max_attempts=1+allow_retry；remaining_attempts=max(0,max_attempts-started_count)。公开任务字段my_remaining_retries沿用历史字段名，值明确表示“剩余可开始次数”，前端文案不写“额外重做”。start即消耗，aborted不退次数；管理员给予追加机会应新任务或显式审核变更，不能修改published任务隐式放宽。

session_snapshot固定题面、rubric全版本/细则、task约束、roster归属、required_tracks和scenario。重算默认沿用原rubric；模型升级可换model_config，不换历史标准；需新标准评分则新练习场次，不覆盖原任务成绩。

## 4 评分与统计

### 4.1 两级公式

第一级：`dimension=100×Σ((item_score/max_score)×item_weight)/Σ(已评分item_weight)`；全部缺失或已评权重和0→unavailable。human项在AI中缺失，不自动填分。

第二级：可用维度≥4且可用原始权重和>0时，`ai_total=Σ(dimension_score×weight)/Σ(available weight)`；否则partial、总分NULL。不可用维度保留六行、score=NULL、effective_weight=0。有效权重按显示精度补偿最后非零项的尾差，但计算始终用原始Decimal比例。阈值与完整参考函数见04 §6。

人工submit必须提供全部item_scores且每项0..max_score；按同一两级算法且六维齐全计算total_score。ai主体也可在主批人工复核中评分覆盖最终分，但原AI细则/总分保持不变；scored_by是初评来源约束，不阻止教师纠正模型。若human必评项没填，拒绝人工提交。

final_score=有效主批total_score，否则当前AI总分；均无则NULL，source=none。grade按当前场次固定grade_bands。AI重算不覆盖已有teacher_score。report的radar.score默认AI维度，effective_dimension_scores在人工主批存在时由review.item_scores算出并供统计/证书；页面须区分AI与教师维度。

### 4.2 指标口径

| 指标 | 计算规则 |
|---|---|
| 语速 | 先16kHz/单声道PCM；VAD有效发声秒数>0后，ASR汉字数/(有效发声秒/60)；不重复扣静音 |
| 停顿 | 活动轴静音段≥300ms计一次；长停顿≥1500ms；avg=总静音毫秒/次数，零次为0 |
| 音量 | PCM16每100ms RMS，20log10(max(rms,1)/32768)，平均帧dB；不拿物理SPL分贝宣传 |
| 稳定性 | clamp(100×(1-std(frame_db)/6),0,100)，包含可用音频帧；缺音频为NULL |
| 流畅度 | clamp(100-1.2×口头禅总数-2×长停顿数-1.5×连续重复词数,0,100)；ASR不可用为NULL |
| 眼神/微笑 | 有效face_detected且confidence≥0.5帧中eye_contact=true/expression≥4比例；无有效帧NULL |
| 候答 | verified句级提问结束到最近被点名虚拟回答开始，1..15秒内配对，不复用回答；无法配对NULL |
| 开放性问题 | 教师ASR问句分类open/(open+closed)；零问句NULL，不默认为0或满分 |
| 纪律处理 | distracted/whisper/noisy事件对应handled投影；0事件评分可满，指标ratio=NULL并说明无事件 |
| 板书占比 | 板书轨每秒相邻帧归一化灰度绝对差>0.03计该秒有变化，变化秒/活动总秒；缺轨NULL；须样本标定 |
| PPT页数 | 屏幕帧感知hash相邻汉明距>12且持续≥1秒计新页；阈值可配置且记录版本，无输入NULL |

口头禅词表预置“嗯/呃/然后/就是说/那个/对吧”，班级可附加；逐词最长优先非重叠匹配，语义歧义保留warnings，不将所有“然后”强认错误；offset仅verified才给精确列表。重复词按相邻2–4字片段连续重复统计；规则版本写attempt.model_config。

### 4.3 环节切分

ASR完成后标点切句，短句合并≥8字；导入词“今天/回忆/上节课”，新授“分析/意思/请注意”，练习“试着/做一做/练习”，小结“总结/回顾/学了”，作业“课后/预习/作业”。同类连续≥3句形成候选；不足3段调用P-SEG；仍不足则source=unavailable，不能按理想占比伪造normal。

标签intro/new_lesson/practice/summary/homework，无法归类为other；边界取相邻句间中点，覆盖活动总时长，不重叠；缺失环节duration_ms=0，segment_timing约束为>=0且start=end合法。actual_ratio合计1，零总时长拒绝评分；五个计划占比 .15/.50/.20/.10/.05，other计划0且不参与超比扣分。必需intro/new_lesson/summary缺每项扣15；计划>0且超plan×1.6每项扣12；总时长超计划扣10，超20%扣20（二者择一），clamp到0..100。

### 4.4 统计与证书

任务提交率分子=roster_snapshot中至少一个finished正式场次的唯一学生数，分母=发布时名单人数；class_stats跨任务按(学生,任务)应交对计分，避免一个学生交一项就算全交；expected=0时submission_rate=0并warning no_expected。活跃人数为区间内至少start一次学生数。

任务成绩取最后已发布有效final_score的finished场次；其他失败/partial场次不覆盖已有成绩。班级平均按该周期应交任务×学生的有效成绩求均值，缺交不当0；各维使用有效主批维度优先，否则AI维度，缺失不填0并带样本量。周为ISO周、月YYYY-MM、学期YYYY-S1/S2（2–7月S1、8–次年1月S2归8月所在年）；全按北京时间边界换UTC查询。

score榜=周期各任务最终有效成绩的学生均值，improvement榜=周期最后有效总分减最早有效总分；少于2份进步为空不入进步榜。并列分数按完成时间早者、user_id稳定排序，不随机排名。grade范围ID必须dim_grade.grade_id，对应cohort_year=enroll_year；学生只见自己所在院系与合法班级/届次/专业范围，school榜仅管理员可查。

进步曲线按自然日将有效场次最终分平均；week/month按session_count加权，不能对每天AVG再次简单AVG。薄弱推送同学生+维度7天最多1条，材料引用必须存在。证书使用effective维度：control→interaction，timing→time_management，board→board_ppt，comprehensive→final；content不单发。要求完整六维、verified、无未处理低置信人工复核、佐证≥1；多份依据取最小成绩达线（不能择最大掩盖未达标），grade_bands来自签发选择的同版本rubric，不混标准。有效期默认2年、不超过2年；需要更长期限走新决议。

## 5 模型输入、提示词与可验证输出

### 5.1 适配器和长音频

国内Base URL使用配置，不将海外文档限制当国内实测结论。默认评分候选glm-4.7-flash、视觉候选glm-4v-flash、ASR候选glm-asr-2512，TTS P1按实际账号支持ID配置。HTTP路径/JSON模式由适配器能力清单记录，不能假定所有接口都接受response_format或句级时间戳。模型任一变更回归G3/G5。

ASR以<=25秒窗口、1秒重叠切PCM；每段<=20MiB；chunk_n全局offset=n×24000ms。音频静音段可跳过但保留全局时间轴，不能拼掉静音导致问题锚点漂移。合并重叠用前段尾部/后段首部最多30字最长公共连续重合串，重复存在歧义则保留chunk边界并warnings；词级offset去重按同text且时间重叠>50%。失败段最多2次重试；缺失段标unavailable，整报告是否可发布按六维有效性判断。

provider有原生时间戳→统一毫秒并验证chunk内单调和越界；缺原生时间戳→只标整chunk粗区间approximate，不按字数平均伪造句级时间。要达到verified需供应商原生能力或另行评审的强制对齐适配器，固定样本证明证据误差。ASR不含每词位置时filler offsets为空并显式approximate。

模型请求输入最多12000汉字ASR文本；超出时按时间块提取证据摘要，保留原句ID/offset映射，摘要不能创造证据。单次评分60秒，视觉30秒，ASR每25秒段60秒；整体600秒预算优先。全局额度记录GLM_MAX_*_CONCURRENCY，未填不允许擅自发50并发。

## 6 规则评测器（可执行纯函数）

输入speech/metric为字典，对缺输入保留None，不把None变0；rubric_items显式参数。规则分先0–100，再按item.max_score缩放，最终两位舍入在04公式中完成。词匹配顺序固定，“开放提问”优先open，不被“提问”吞掉；命中不可评普通话保持NULL。

```python
def piecewise(x, pts):
    if x is None:
        return None
    if len(pts) < 2 or any(b[0] <= a[0] for a, b in zip(pts, pts[1:])):
        raise ValueError("invalid_points")
    x = float(x)
    if x <= pts[0][0]:
        return float(pts[0][1])
    if x >= pts[-1][0]:
        return float(pts[-1][1])
    for (x0, y0), (x1, y1) in zip(pts, pts[1:]):
        if x0 <= x <= x1:
            return y0 + (y1 - y0) * (x - x0) / (x1 - x0)
    raise ValueError("unreachable")

KEYWORDS = [
    (("普通话", "发音"), "mandarin"), (("开放",), "open"),
    (("候答", "等待"), "wait"), (("语速", "语流"), "speed"),
    (("停顿", "节奏"), "pause"), (("音量", "声音"), "volume"),
    (("口头禅", "填充词", "赘语"), "filler"), (("流畅", "连贯"), "fluency"),
    (("提问", "设问"), "question"), (("纪律", "控场", "管理"), "discipline"),
    (("鼓励", "反馈", "评价"), "encourage"), (("环节", "时间分配", "流程"), "time"),
]

def map_to_items(metrics, rubric_items):
    values = [v for v in metrics.values() if v is not None]
    fallback = sum(values) / len(values) if values else None
    result = {}
    for item in rubric_items:
        if item["scored_by"] == "human":
            continue
        mapped = next((key for words, key in KEYWORDS if any(w in item["item_name"] for w in words)), None)
        value = metrics.get(mapped) if mapped else None
        # 命中“发音”但值NULL时保持缺失，不走均值兜底
        if value is not None:
            value = max(0., min(100., float(value)))
            result[item["item_id"]] = round(value * float(item["max_score"]) / 100., 4)
    return result

def score_expression(speech, filler_hits, stage, total_s, rubric_items):
    limits = {"preschool": (110,130,190,240), "primary": (130,150,220,280),
              "junior_high": (150,180,260,320), "senior_high": (150,180,260,320),
              "vocational": (150,180,260,320)}
    lo, il, ih, hi = limits[stage]
    speed = piecewise(speech.get("speed_wpm"), [(lo,0),(il,100),(ih,100),(hi,0)])
    n, avg = speech.get("pause_count"), speech.get("avg_pause_ms")
    pause = None
    if total_s > 0 and n is not None and avg is not None:
        pm = n / (total_s / 60.)
        dev = max(0, 6-pm)/6 + max(0, pm-15)/15 + max(0, 300-avg)/300 + max(0, avg-800)/800
        pause = max(0.,100*(1-dev))
    volume = piecewise(speech.get("volume_avg_db"), [(-50,0),(-30,0),(-20,100),(-12,100),(0,40)])
    filler = None if filler_hits is None else max(0.,100 - max(0.,sum(f["per_minute"] for f in filler_hits)-3)*12.5)
    metrics = dict(speed=speed,pause=pause,volume=volume,filler=filler,
                   fluency=speech.get("fluency_score"),mandarin=None)
    return map_to_items(metrics,rubric_items)

def score_interaction(metric, stage, total_s, rubric_items):
    def per10(value):
        return None if total_s <= 0 or value is None else value * 600. / total_s
    def scale(value, target):
        return None if value is None else max(0., min(100., value / target * 100))
    question = piecewise(per10(metric.get("question_count")), [(0,0),(3,40),(6,85),(8,100),(12,100),(16,60),(20,0)])
    wait = piecewise(metric.get("wait_time_avg_ms"),[(0,0),(500,30),(2000,100),(5000,100),(8000,50),(15000,0)])
    de = metric.get("discipline_events")
    discipline = None if de is None else 100. if de == 0 else scale(metric.get("discipline_handled_ratio"),1)
    metrics = dict(question=question, open=scale(metric.get("open_question_ratio"),.4), wait=wait,
                   discipline=discipline, encourage=scale(per10(metric.get("encourage_count")),3))
    return map_to_items(metrics,rubric_items)

```

以上stage参数为扩展点，当前互动阈值统一10分钟口径，不谎称学段差异已实现。规则未命中细则保留NULL，禁止将其他指标均值填入；未命中>50%记录rule_mapping_poor，需要人工复核；human项不参与均值填补。时间规则见§4.3；只要环节source=unavailable，该维也unavailable。board仅有使用时长且细则明确针对使用时才可给规则分，结构项NULL。

阈值问题：语速>hi/低于lo、口头禅>3次/分、音量<-30dBFS、10分钟提问<3、开放率<.2、鼓励0、有纪律事件但处理率<.5、必需环节缺失或>plan×1.6。严重度high为口头禅>6/分、语速超过hi×1.3或低于lo×.7；其余mid。偏移来自输入证据，找不到精确片段可整段粗定位，不伪造秒级点。

## 8 媒体协议与前端约定

### 8.1 采集、上传与恢复

MediaRecorder.isTypeSupported依次探测video/webm;codecs=vp9,opus、vp8,opus、video/webm；音频audio/webm;codecs=opus，实际支持再选。require_video=true无可用视频/摄像头拒绝start；自由音频练习可只audio，但教态/板书缺失按真实可用性处理。

5秒dataavailable先序号化写本地IndexedDB，可用空间不足明确暂停并提示，内存最多保留一个8MiB聚合part及当前采集blob。每轨串行合并字节流，最多2个上传并发；本地持久化成功后方可释放内存。队列记录upload_id/track/part_no/hash/bytes，不保存服务端永久凭据。浏览器数据库加用户隔离，退出清理未授权草稿需提示用户；保存媒体需要archive授权或本次会话内明确临时存储许可。

最后stop后等待末次dataavailable与onstop，再flush末片、await所有上传；GET parts核实→complete服务端封存→收集Recording→计算manifest→session submit。只有upload.status completed才可引用点评/训练/资源。页刷新后仅恢复IndexedDB仍有的分片与服务端已有part；权限变更或清理导致片段丢失则该录制incomplete并建议重做，不能自动append新容器装作同一媒体。

单轨5–45分钟可超预签URL有效期，所以动态签URL。总和>2GiB直接413并停止继续签新part。part hash重发一致幂等，乱序保存清单，complete按顺序拼，不依赖网络返回顺序。S3完成后服务端读取合成对象算SHA256，不能拿multipart ETag代替。

### 8.2 API客户端

req支持JSON/FormData/二进制三种body；仅JSON设Content-Type，FormData交浏览器设置boundary。先检查204并直接返回undefined，再按Content-Type解析。Problem取type最后一段（URN冒号末段），HTTP失败不能当success=code1处理；401 token-expired单飞refresh后重试一次，session-revoked直接清身份重新登录。refresh成功必须同时保存新access和refresh，不继续用已轮换旧token。

access/refresh只放sessionStorage，业务目录/成绩不缓存为事实；本地录制IndexedDB是明确允许的媒体续传用途，不与“业务数据全走API”混淆。退出清token、撤销sid、关闭WS/WebRTC；切换账号不得复用上一个用户上传队列。create/start/submit请求保存幂等key直到结果确定，超时重试不新造key。

### 8.3 页面与图表

唯一正式前端为app/frontend的Vue3+TypeScript+Vite工程，npm依赖由package-lock.json固定，npm ci后构建dist；离线演示也使用该产物，不再维护第二套零构建页面。所有页面使用同一DTO/路由：登录、强制改密、任务、资源、课堂、我的录制、报告、教师标准/任务/批阅、班级、用户/审计/导出、成长/训练/考核/证书与公开验真。

雷达缺维显示“不可评”而非0；AI和人工有效维度分开；latest_attempt失败保留旧成绩并提示重算失败。verified/approximate锚点标记清楚；rules/cached_demo显式标识。所有状态见07，无隐藏假数据。

上传resource在目标实体未创建时，target_id=owner user_id表示暂存空间；成功后首次绑定资源记录，其owner/department和upload用途一起校验，metadata_json写bound_target_id，禁止第二资源复用可变上传。avatar target_id必须本人user_id、图像≤5MiB，解码检查后再更新头像；review_voice/training/exam必须绑定已存在的场次/训练/考核。媒体用途不能只因为用户有任一权限就全部开放。

### 11.2 考核全程录像与成绩

exam.full_video_required=true：备课/试讲/答辩使用单独purpose=exam录像，target=exam_id，最多3个连续阶段对象，单轨≤2GiB；上传协议同media-uploads，记录墙钟轴metadata={axis:exam_wall,phase,start_at,end_at}。试讲另有session活动轴轨道，不能拿10分钟试讲录像声称覆盖35分钟考核。入defense时若试讲仍running/paused，先finish并封存，异步等待必需轨上传；正式submit要求试讲session已submit及全场录像complete。全场各阶段wall区间不得有缺口>5秒；缺口明确不完整并拒绝正式考核通过。

考核submitted后等待trial报告可用、alignment_quality=verified、全场录像完整、答辩答案齐全；由管辖且is_examiner=true教师POST /exams/{exam_id}/grade提交全部冻结考官rubric细则与评语，服务端同公式计算final_score/result，examiner_review_json保存输入审计，事务置finished。AI trial分是参考依据，不能直接冒充全考核分；客户端无total_score字段。备课超时自动进入trial仍须设备与授权可用，否则abort；试讲超时finish→defense；答辩超时以已有答案/录像检查提交，材料不足abort并给原因，不填默认答案。考核训练绑定training_record.exam_id，完成成绩取该考核最终分。

### 11.3 保留、截止与媒体上限

最长活动时长45分钟为硬上限，2倍计划与45分钟较早者强制finish（有完整轨可submit）；主动中断/故障才abort。暂停墙钟超过30分钟abort。complete基于FFprobe确认轨道时长和字节，正常正式录制≥5分钟；异常片段可以封存用于回看，但不足正式要求不能submit评分。未开始即abort允许actual_duration_s=0且无start_at，不生成假时段。

session_snapshot冻结配置，runtime_json存候选状态/答案池/设备flags；候选池生成后不可随意换题，start锁其hash。当前恢复snapshot是运行状态投影，与配置session_snapshot不是同一个字段。
