## 1 引言与系统边界

面向师范生训练、指导教师批阅和校内质量管理，支持身份组织、虚拟课堂、录制观摩、六维评测、建议反馈、资源题库、阶梯训练、管理后台、达标认证九个模块。保留原FR编号，便于迁移已有测试。系统不提供官方教资成绩认定，不接管教务学籍总库，不提供真实中小学在线授课或通用IM。

## 2 用户、环境与假设

学生只操作本人；教师访问managed/advisor班级；教研管理员访问本院department；系统管理员全校运维。department是真实组织维度，与V2多校school_id分离。管理员无教师评分权限，需教师角色执行批阅。

服务端Python3.12/FastAPI/Pydantic2/SQLAlchemy2；开发MySQL8，交付SQL Server，生产Redis7与S3兼容对象存储。前端Chrome/Edge目标版本须过兼容测试；唯一正式前端为app/frontend的Vite+Vue3+TypeScript工程，依赖按lock冻结。摄像头/麦克风需安全上下文和明示授权；公网需HTTPS。

GLM为首选云模型适配器。模型标识与配额须按实际账号记录；短音频连通、长音频时间轴、评分效果分别验证。字迹与音素级发音评分不属于MVP；不能把NULL当0或默认满分。

优先级定义：P0 = MVP 必须；P1 = V1.0 必须；P2 = V2 增强。每条需求含编号、描述、验收要点。

### 3.3 FR-03 试讲录制与直播（P0）

### 3.4 FR-04 AI 多维度评测（P0，核心价值）

六维评测，每维包含细则项（rubric_item），支持 AI 评分 + 教师复核：

| 维度 | 评测输入 | 关键指标 |
|---|---|---|
| 教学内容 | ASR 文本 + 题面基准（LLM） | 知识点准确性、逻辑清晰度、重难点把握、讲解完整度 |
| 教学表达 | 音频 + ASR | 普通话标准度不评分（NULL）；语速、停顿、音量、流畅度、口头禅频次 |
| 教姿教态 | 人像视频抽帧（视觉模型） | 采样帧姿态规范度、手势、眼神注视率、微笑占比；单帧方案movement_score=NULL |
| 互动控场 | 行为事件 + ASR 语义 | 提问次数、开放问题占比、候答时长、反馈质量、纪律处理率、节奏分 |
| 板书 PPT | 板书轨 + 屏幕轨（**MVP 不做 OCR，不评字迹**，决议 D5） | 板书结构分、PPT 合理性、板书时间占比；字迹工整度字段恒为NULL |
| 时间管理 | ASR 环节切分 | 导入/新授/练习/小结/作业各环节时长与占比、超时/缺失标记 |
| 编号 | 需求 | 验收要点 |
|---|---|---|
| FR-04-1 | 评测流水线：逐轨上传校验→session submit→ASR/视觉/板书并行→ASR完成后做文本/环节/互动语义→细则评分→发布快照 | 真实10分钟录制从submit被接受起5分钟内发布率≥95%；300s告警，600s失败；排队时间计入；缺少输入可partial，新尝试失败保留旧结果 |
| FR-04-2 | 报告结构：总分 + 六维得分 + 细则项 + 证据（offset_ms 锚点）+ 置信度 | 只有alignment_quality=verified的证据承诺精确定位；approximate明确标粗定位 |
| FR-04-3 | 教师复核并存：保留 ai_total_score；仅**有效主批（`is_primary=1 AND status='reviewed'`）**的 total_score 写入 teacher_score 并作为 final_score，否则 final_score 取 AI 分 | AI尝试快照不可变，当前结果为投影；有效主批分由人工细则服务端计算；改分产生score.changed事件 |
| FR-04-4 | 可追溯：报告记录 rubric_version、ai_model_version、topic_snapshot | 题面、rubric、模型、时间对齐质量及attempt快照可追溯；重算不覆盖旧快照 |

## 4 非功能需求

| 编号 | 指标 | 验收边界 |
|---|---|---|
| NFR-1 | 常规REST P95≤500ms，错误率<0.1% | 不含媒体传输/异步任务；记录测试资源和负载 |
| NFR-2 | 控制WS消息P95≤300ms；指导消息≤1s；点名作答≤1.5s | 预生成候选池；1学生+最多4真实观摩者，60虚拟学生不单建连接 |
| NFR-3 | 目标200场并发、50路ASR | 设计目标，目标环境实测前不得承诺；ASR请求与流水线并发分别限制 |
| NFR-4 | 10分钟真实录制submit接受后5分钟发布率≥95% | 排队+预处理+外部调用+落库全计；300s告警，600s本次attempt失败 |
| NFR-5 | 每轨≤2GiB；录制5–45分钟 | 按实际字节和时长校验；内存缓冲有上限；本地磁盘容量不足必须阻止继续采集 |
| NFR-6 | 学期核心服务可用性目标99.5% | 健康监控、恢复演练；memory形态不等于无SQL持久化 |
| NFR-7 | 鉴权逐资源校验，权限撤回下一请求生效 | auth_version+security_session在线校验；文件和WS鉴权同标准 |
| NFR-8 | 明示授权、撤回留痕、到期清理 | portrait/voice/analysis分开，撤回阻止后续分析；保留依学校批准规则配置 |
| NFR-9 | 1366×768/1920×1080，Chrome/Edge兼容矩阵 | codec探测、WebRTC直连与TURN、摄像头权限异常 |
| NFR-10 | API、迁移、日志与版本可追溯 | OpenAPI导出与06/11比对；req_id、attempt_id、score_version贯通 |
| NFR-11 | 重算和派生数据最终一致 | outbox事务、消费去重；同一report的旧score_version不得覆盖新值 |
| NFR-12 | 暂停前后媒体/场次同轴 | 服务端活动时钟；暂停所有recorder（pause，不调用stop）；对齐差≤5s，verified证据≤0.5s |
| NFR-13 | 观摩音视频延迟目标P95≤2s | 单场4观摩、直连与TURN分别测；失败显示媒体断开，不伪装正在观摩 |

## 5 外部接口与数据要求

REST `/api/v1`、WSS `/ws/sessions/{session_id}`；WebRTC仅传音视频，WS只传业务事件与定向信令。数据字段见05，DTO见11，逐端点权限见06。对象存储只持久化key，禁止把预签名URL写业务表。

报告、评分标准、题面、模型和证书规则均有快照。训练开始必须可保存running状态；pending批阅允许总分NULL；缺失维度保留六行并标unavailable。目标数据库61表，迁移以05为准，原52表DDL不作为新基线。

## 6 保留、删除与授权

录制默认180天，可续期至创建日起3年。批阅中的录制锁定到lock_until；到期清理按锁定与续期较晚者执行且不越3年。撤回授权即abort running/paused、取消尚未发出的云分析任务，不自动删除已完成批阅证据；删除申请按保留规则受控处理，记录理由和审计。撤回与删除是不同动作。

行为事实/报告保留3年，审计180天，导出7天，证书永久记录可撤销；不得默认授权原始人像声音用于模型训练。

## 7 验收与追踪

MVP覆盖所有P0：教师创建并发布rubric/任务→学生授权并按任务开课→真实录制及实时观摩→逐轨校验→submit→报告→教师批阅/主批→统计/导出。V1.0增加跟读、考核、TTS、证书与完整成长闭环。演示缓存必须标识，不能代替真实路径验收。

功能、故障和权限用例见08；实施门禁G1–G6见12。AI效果要求固定≥50份样本，双盲平均绝对偏差≤8分，知识错误准确率≥85%/召回≥75%，ASR CER≤8%，建议可用率≥80%。未达标的能力进入人工复核或partial，不降低门槛后声称通过。
