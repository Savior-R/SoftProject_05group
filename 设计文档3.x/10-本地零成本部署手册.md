## 1 目标和现状

复用本机SQL/Python/浏览器，尽量不新增基础设施支出。模型/短信/公网TURN可能收费，免费额度以账号当时为准；本地零成本不代表模型永久免费。当前已有最小后端，frontend、目标迁移、seed 和业务链路仍按实施状态交付；部署配置不代表系统可用。环境与完成范围见 app/IMPLEMENTATION_STATUS.md，本次基准统一未重测机器安装。

## 2 本机模式

| 模式 | 行为 | 可证明范围 |
|---|---|---|
| A1+glm | 真实网络/账号/模型，可用性与对齐如实返回 | 单机真实闭环，效果仍需固定样本 |
| A1+rules | 只评可算指标，缺维partial，不默认内容高分 | 录制/上传/规则/批阅流程 |
| A1+cached_demo | 精确media SHA256/标准/模型配置匹配已验证缓存，有标签 | 指定样本回放，不证明新录像实时分析 |
| A2 | Redis+arq，契约不变 | 异步/限流/恢复，不证明生产容量 |

保留六人设、三模式、四角色与全部P0页面；四页面/三人设子集不能标整版验收。

## 4 数据库先行

按05生成61表初始化/存量迁移并跑G1，不能直接用旧数据库基本模型脚本认定符合本版。账号有7库/7schema权限，密码不写命令行历史；已有数据先备份，不直接清库。

最小断言：pending主批无总分可落库；有效reviewed唯一；returned释放；训练running完成时间NULL合法；缺维score=NULL合法；满分0拒绝；院系归属一致；session_event序号唯一。文本转换不等于SQL Server执行成功。

## 6 配置和启动（工程完成后）

本机.env按09设置DATABASE_URL、ENV=demo、QUEUE_BACKEND=memory、STORAGE_BACKEND=local、MEDIA_ROOT绝对目录、强JWT密钥及AI_MODE；真实模型设已验证GLM配置/并发。mock短信仅demo，不能公网注册。

启动命令/目标模块见09 §4，先迁移→seed manifest→单API→前端代理。seed按11验证关系，账号随机密码只交操作者一次，不提供固定公网默认口令。A2另配Redis/arq，A1不强加Redis。同源代理/api/v1和/ws；不能file://打开HTML期待模块/API/设备权限正常。健康检查不等于业务验收。

## 7 真实黄金路径

1. 管理员建院系/专业/班级和账号；教师登录完成强制改密、重新登录并签授权。
2. 教师建六维标准/grade_bands/scored_by，显式publish；创建发布任务，核对名单、模式、题目、时长、视频与最多开始次数。
3. 学生授权后POST /api/v1/sessions创建；候选ready且设备合格，POST /api/v1/sessions/{session_id}/start，服务端绑定任务约束。
4. 真实试讲，至少一次pause/resume，教师真实音视频观摩并指导；虚拟学生不是独立媒体连接。
5. POST /api/v1/recordings/init建轨道，blob聚8MiB动态签URL上传；finish只结束课堂，等待stop末片和全部上传，再逐轨POST /api/v1/media-uploads/{upload_id}/complete封存。
6. 显式POST /api/v1/sessions/{session_id}/submit提交manifest；202后GET /api/v1/reports/{session_id}观察结果；缺维partial，不能把别的录像缓存套入。
7. 教师认领pending，完整细则submit reviewed并设主批；最终分来自教师且AI原分保留。改分后观察统计60秒刷新，P1另验证榜单/曲线/证书复核。
8. 学生回看、区分verified/粗定位并采纳建议；导出下载；退出204无解析异常，旧refresh不能登录。

快速彩排最短合法5分钟；10分钟用于真实链路与SLA，45分钟用于上传/分段边界。短彩排不替代长样本门禁。

## 8 展示与验收

五分钟讲解可用预先授权录像/已生成报告，开场标“预先生成/缓存回放”。现场1分钟录制是设备展示，不是5–45分钟业务验收；不能临时放宽正式约束来伪装通过。

断网仅rules可算指标继续，缺维NULL；精确匹配缓存可标识回放，其他录像不能套分。保留真实失败和request_id；演示前分别检查离线资源与联网真实闭环，不混合两者结论。

## 9 排障

| 现象 | 处理 |
|---|---|
| 缺app.main/requirements.lock/seed | 目标工程尚未交付，先按09实现入口 |
| SQL Server索引报错 | 不把计算列放filter；用普通列并重新生成 |
| finish没报告 | 先查必需轨complete和显式submit，不让finish触发评测 |
| S3 EntityTooSmall/InvalidPart | 检查blob错当part、非末片大小、顺序/ETag |
| 新录像断网无总分 | 查AI_MODE与可用维度，不填默认内容分 |
| 图表空白 | frontend/dist 的构建产物、资源路径和CSP，不依赖CDN |
| WS通但无画面 | 查offer/answer/ICE/TURN/权限，控制与媒体分开 |
| 收权仍可访问 | 查SQL auth_version/sid与scope，不纯信旧JWT |
| 重启不能续讲 | 按保守abort，仅恢复已存上传，不伪拼新容器 |
| 本机资源不足 | 依据CPU/内存/磁盘缩小演示，不声称生产并发达标 |
