## 1 设计原则与交互边界

学生主线为任务→准备→试讲→提交→反馈→改进；教师主线为标准→任务→观摩→批阅→统计。页面根据06/11真实状态展示，按钮隐藏不是权限控制。设计稿、占位图和cached_demo明确标来源，没有数据时显示空态。

适配1366×768和1920×1080，完整多轨录制为桌面优先。设备权限弹窗前说明用途，拒绝后给设置入口和允许的音频模式；require_video任务不能绕过摄像头校验。

## 2 角色与页面矩阵

| 页面 | 角色/范围 | 主操作与异常态 |
|---|---|---|
| 登录/注册/找回/强制改密 | 未登录或本人 | 注册仅学生，短信模拟标demo；锁定剩余秒数；改密后重新登录 |
| 个人中心/授权 | 四角色本人 | 档案、头像、改密、分项授权及撤回、当前院系 |
| 任务列表/详情 | 学生分配；教师管辖；管理员范围 | 条件、截止、已开始/剩余可开始次数；无任务空态 |
| 题库/模板/范例 | 本院及系统共享 | 多维筛选、结构化十类、content_json正文；学生不见参考答案 |
| 课堂准备/虚拟课堂 | 学生本人 | 任务参数锁定、设备、候选池准备、录制、互动、上传 |
| 实时观摩 | 教师管辖/教研管理员本院 | WebRTC音视频、媒体状态、课堂事件；指导单独鉴权 |
| 我的录制/回放 | 本人或教师管辖 | 轨道、时长、上传、保留/锁定、标记、续期、删除 |
| 报告/证据/建议 | 本人/教师管辖/管理员范围 | 当前有效分、AI原分、latest_attempt、六维、问题证据、行动 |
| 标准编辑/发布 | 教师本人/教研管理员本院/系统管理员共享标准 | 权重、细则、主体、分数线、发布与新版本 |
| 教师任务/提交列表 | 教师管辖/教研管理员本院 | 创建发布截止、名单、学生提交/次数、批阅进度 |
| 批阅工作台 | 教师管辖 | 认领、暂存、完整提交、主批、退回、reopen、语音点评 |
| 班级/小组/统计 | 学生本班只读；教师/管理员范围 | 导入、老师分配、小组、统计、导出 |
| 训练/模拟考核（P1） | 学生本人 | 跟读、完整试讲、情景、20/10/5阶段、服务端评分 |
| 成长/榜单/证书（P1） | 本人或管理员权限 | 曲线、成绩/进步榜、薄弱训练、证书及复核 |
| 用户/院系/审计/导出 | 教研管理员本院/系统管理员 | 组织、账号、重置、审计；改权限仅sys_admin |
| 公开验真 | 公开 | 脱敏姓名、技能、等级、有效/待复核/撤销/到期 |

导航由me权限与scope生成，收权返回session-revoked立即清身份并关闭WS/WebRTC。URL中report参数为session_id，不与稳定report_id混用。

## 3 账号、标准和任务入口

注册不预勾选授权，不允许自行注册教师/管理员；院系由专业/班级派生。强制改密只能改密或退出，普通登录不清标记。改密成功提示重新登录。

标准编辑器固定六维，显示总权重/各维细则权重和、满分、scored_by与等级线；满分0及时报错。显式发布后正文只读，“编辑新版”创建draft而不覆盖旧场次。教师仅个人标准，系统/校级标准由系统管理员维护。

任务发布前核对班级名单、模式/题目、标准版本、时长/视频、截止、额外重做数。显示“首讲1次+额外3次=最多开始4次；中断也消耗已开始机会”。发布后冻结，截止不能start；后续名单导入不悄悄修改发布分母。

## 4 课堂、录制和观摩

全屏课堂左侧题面/投影，中部座位区，右侧环节/事件/指导，下方控制栏和录制预览。1–28人4列，29–60人6列；六类人设使用图标和文字，不能只靠颜色。

| 场景 | 界面与服务端一致行为 |
|---|---|
| not_started | 授权、候选ready、设备/必需轨全部满足才开放start |
| running | 活动倒计时、各轨采集中、虚拟事件；允许pause/finish |
| paused | 全轨recorder.pause、时钟停止、观摩停止发媒体；保持控制连接 |
| finish | 确认结束后依次显示整理末片→上传→校验→待提交；未入评测队列 |
| 必需轨完成 | 列明可选无输入轨，开放“提交评测”；202后进入报告进度 |
| 网络中断 | 显示本地分片/空间/重试；查询清单只补缺片，沿用upload_id |
| 刷新 | 仅恢复已持久化片段；新媒体容器不能拼装冒充原连续录制 |
| 必需轨缺失 | 标不完整、拒绝submit、给重做入口，不补假黑屏 |
| 服务重启 | 场次保守aborted，已存片段可查；不伪装可续讲 |

“结束课堂”和“提交评测”分两步。5秒blob是采集单位，8MiB part是上传单位，进度按真实确认字节。stop后等待最后dataavailable、全部上传与逐轨complete，不能先跳成功页。相同key重试，不因超时重复创建场次。

教师先领一次性ticket与RTC配置，展示连接中/直连/TURN/媒体中断；最多4位真实观摩者，5人提示满员。WS文字指导成功不代表媒体成功。断线重领票，以last_seq重放，过7天窗口用snapshot reset；界面按seq去重。学生不收到答案池或教师参考答案。

## 5 报告与批阅

报告先展示当前最终分、来源、等级，再展示AI原分/教师分、六维、问题、建议。latest_attempt单独显示，新重算失败保留旧成绩并说明失败步骤；初次partial显示“输入或能力不足，暂不能形成总分”，不是0分。

雷达缺维显示“不可评”并断线/留空，旁列原因；AI维度和人工有效维度使用明确图例。班级基准注明周期、样本数、更新时间；rules标规则分析，cached_demo标缓存演示及原生成时间。不能用0填NULL。

verified证据提供精确跳转，approximate显示约X–Y秒粗定位，unavailable禁用跳转。播放器0.5–2倍速、字幕、键盘控制；所有offset排除暂停，与活动轴一致。

批阅左右并排视频/细则，支持Tab和暂存；pending可部分填写，完整提交须全细则。已有有效主批时提示，争抢409刷新而不覆盖别人；退回需理由，reopen后再提交。批量混合结果逐条显示，失败行保留内容。

语音点评探测codec，最长300秒/10MiB，统一media-uploads封存后传voice_upload_id；不强制浏览器原生录m4a。录制/上传/可播/失败/重录状态明确。改分后显示统计更新中，不在前端伪算班级成绩。

## 6 录制、训练、考核、证书

我的录制显示保留期和lock_until，锁定删除置灰并解释日期，服务端仍校验；到期前7天提醒，续期最多created_at+3年，删除二次确认。授权撤回按11独立处理，不能用删除按钮代替。

跟读文案仅语速/停顿/口头禅比对，不称音素发音测评；训练由服务端评分，失败如实显示。考核显示备课20min→试讲10min→答辩5min→提交评分，以服务端deadline为准，刷新不重新计时，提前切换确认；显示全场录像/试讲轨/答辩答案完整性。

证书pending_review明确“依据变更，待复核”，验真false；retain须重新达标，revoke有原因且不可逆。公开只脱敏身份。进步榜不足2份成绩不强算进步，图表显示更新时间和stale。

## 7 通用规范

列表具有loading/empty/error/forbidden四态。Problem.type映射中文并可复制request_id；202显示真实进度，导出expired提供重新申请；204不解析JSON。危险操作说明对象和后果，输入草稿与IndexedDB媒体队列按用户隔离；退出关闭设备和连接，不复用前账号上传队列。媒体通过鉴权短链播放。

## 9 无障碍与验收

文本对比度目标4.5:1，状态同时用文字/图形，可见焦点、Tab顺序、读屏标签、字幕、减少动效偏好；强制改密不允许Esc绕过。课堂关键提示不被气泡遮挡，图表缺维不以颜色暗示0分。人工可用性与浏览器兼容结果随G6提交，本设计稿不代表已检测通过。
